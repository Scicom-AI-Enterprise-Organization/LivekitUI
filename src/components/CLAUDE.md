# src/components

## ui/ — shadcn/ui primitives

Generated by the shadcn CLI (`components.json`). Treat them as vendored: prefer passing `className` or composing at the call site over editing these files, so a future `shadcn add` doesn't clobber local changes. If a primitive genuinely needs a new variant, add it to the `cva` block rather than forking the component.

`sonner.tsx` exports the themed `Toaster`. It is mounted once in `src/app/layout.tsx` inside `ThemeProvider` (it reads `useTheme`), so any page can just `import { toast } from "sonner"`.

## livekit/ — dashboard components

App-specific, safe to change freely.

- `sidebar.tsx` — nav tree. Adding a page means adding it here; nested pages go in a parent's `children`. Also redirects to `/login` if `/api/auth/me` 401s, which covers a session lapsing while a tab sits open.
- `top-bar.tsx` — page header: `title`, `breadcrumb`, `actions`, optional refresh/time-range controls.
- `list-state.tsx` — `ListLoading`, `ListError`, `ServiceNotice`. `ServiceNotice` is the "this LiveKit service isn't deployed" explainer; pair it with the `notice` from `useApiList`.
- `data-table.tsx`, `stat-card.tsx`, `line-chart.tsx`, `donut-chart.tsx`, `time-range-picker.tsx` — presentational.
- `console/` — the agent console (live session view).

## Theming

Colors come from CSS variables in `src/app/globals.css`, switched by `next-themes` (`attribute="class"`). Use semantic Tailwind tokens — `bg-card`, `text-muted-foreground`, `border-border` — never raw palette values, or dark mode breaks. `brand-provider.tsx` / `brand-tokens.ts` layer per-brand overrides for the design-system pages.
